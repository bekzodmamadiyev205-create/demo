# FulfilPro

FulfilPro — fulfillment va yetkazib berish jarayonlarini boshqarishga mo‘ljallangan responsive front-end demo.

## Ishga tushirish

Loyihada build bosqichi yo‘q: `index.html` faylini brauzerda oching yoki GitHub Pages orqali nashr qiling.

## GitHub Pages

Repository **Settings → Pages** bo‘limida **Deploy from a branch** usulini tanlang, so‘ng `main` branch va `/ (root)` papkasini saqlang.
